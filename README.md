# BookShop Website

## Project Overview

BookShop is a responsive online bookstore website developed as part of my university web development coursework. The project demonstrates my understanding of front-end web development using HTML, CSS and JavaScript.

The website allows users to browse a selection of books, add items to a shopping cart and proceed through a checkout process.

## Technologies Used

- **HTML5** – Used to structure the website and its content.
- **CSS3** – Used to style the website and create a responsive layout.
- **JavaScript** – Used to implement interactive features, shopping cart functionality and form validation.
- **Session Storage** – Used to temporarily store shopping cart information.

## Key Features

- **Book Catalogue:** Displays a selection of books available to browse.
- **Shopping Cart:** Allows users to add and remove books from their cart.
- **Dynamic Price Calculation:** Automatically calculates the total cost of selected books.
- **Checkout Page:** Displays an order summary and allows users to enter payment information.
- **Form Validation:** Checks user inputs before allowing checkout to proceed.
- **Order Confirmation:** Displays a success page after the checkout form is completed.
- **Responsive Design:** Adapts the website layout to different screen sizes.

## How to Run the Project

1. Download or clone this GitHub repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Open `index.html` in a web browser.
4. Browse the website and test its features.
